# System Design

## 1. Introduction

This section explains the design and structure of the E-WasteTrace Rwanda system. It describes how the system will work and how users will interact with it.

## 2. System Components

- **User Interface:** Allows users to access and interact with the system.
- **User Management:** Manages user registration and login.
- **Waste Reporting:** Allows users to report electronic waste.
- **Collection Management:** Helps administrators organize waste collection.
- **Tracking System:** Monitors electronic waste collection and recycling status.
- **Database:** Stores and manages system information.

## 3. System Design Diagrams

This section will contain:

- System Architecture Diagram.
- Use Case Diagram.
- Data Flow Diagram.
- System Flowchart.

## 4. System Objectives

- Design a simple and user-friendly system.
- Make electronic waste reporting easier.
- Improve waste collection management.
- Track electronic waste activities.
- Support proper electronic waste recycling.

## 5. Expected Results

The system design will provide a clear structure for developing an effective electronic waste management and tracking platform in Rwanda.
