# E-WasteTrace Rwanda

## 1. Project Overview

E-WasteTrace Rwanda is a digital platform designed to improve electronic waste management in Rwanda. The project aims to make it easier to report, collect, monitor, and track electronic waste while promoting responsible recycling and environmental protection.

## 2. Problem Statement

Electronic waste, such as old computers, mobile phones, televisions, and batteries, can cause environmental pollution when it is not properly managed.

This project aims to address challenges in electronic waste reporting, collection, monitoring, and recycling.

## 3. Project Objectives

- Promote responsible electronic waste disposal.
- Make electronic waste reporting easier.
- Improve waste collection and tracking.
- Connect users, collectors, and recycling centers.
- Support environmental protection in Rwanda.

## 4. Main Project Features

- User registration and login.
- Electronic waste reporting.
- Waste collection management.
- Electronic waste tracking.
- Administrator management.
- Database for storing information.
