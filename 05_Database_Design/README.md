# Database Design

## 1. Introduction

This section describes the database design for the E-WasteTrace Rwanda system. The database will store and manage information about users, electronic waste reports, collections, recycling centers, and administrators.

## 2. Main Database Tables

- **Users:** Stores user information.
- **E_Waste:** Stores details about electronic waste.
- **Reports:** Stores electronic waste reports.
- **Collections:** Stores waste collection information.
- **Recycling_Centers:** Stores recycling center details.
- **Administrators:** Stores administrator information.

## 3. Database Objectives

- Organize electronic waste information.
- Store user and report details.
- Track waste collection activities.
- Manage recycling center information.
- Maintain accurate and accessible records.

## 4. Expected Results

The database will support efficient information management and help the E-WasteTrace Rwanda system track electronic waste from reporting to recycling.
