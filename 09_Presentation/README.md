# Project Presentation

## 1. Introduction

This section presents the E-WasteTrace Rwanda project, its purpose, major features, and expected contribution to electronic waste management in Rwanda.

## 2. Project Objectives

- Promote responsible electronic waste disposal.
- Make electronic waste reporting easier.
- Improve waste collection and tracking.
- Connect users, collectors, and recycling centers.
- Support environmental protection.

## 3. Main System Features

- User registration and login.
- Electronic waste reporting.
- Waste collection management.
- Electronic waste tracking.
- Administrator dashboard.
- Information management.

## 4. Expected Benefits

- Improved electronic waste management.
- Increased public awareness.
- Better coordination between stakeholders.
- Responsible recycling practices.
- Reduced environmental pollution.

## 5. Conclusion

E-WasteTrace Rwanda aims to use technology to improve electronic waste reporting, collection, and recycling while promoting a cleaner and safer environment.
