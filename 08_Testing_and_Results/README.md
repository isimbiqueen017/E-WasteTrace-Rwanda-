# Testing and Results

## 1. Introduction

This section explains how the E-WasteTrace Rwanda system will be tested to ensure that it works correctly and meets the project requirements.

## 2. Types of Testing

- **Unit Testing:** Tests individual parts of the system.
- **Integration Testing:** Checks whether different system components work together.
- **System Testing:** Tests the complete system.
- **User Acceptance Testing:** Checks whether the system meets users' needs.

## 3. Testing Objectives

- Identify and correct errors.
- Ensure that users can report electronic waste.
- Verify that information is stored correctly.
- Check the tracking and collection processes.
- Ensure that the system is easy to use.

## 4. Expected Results

The testing process is expected to identify problems and improve the reliability, performance, and usability of the E-WasteTrace Rwanda system.

## 5. Conclusion

Testing will help ensure that the system meets its requirements and supports better electronic waste management in Rwanda.
